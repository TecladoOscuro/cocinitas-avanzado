# Alta Cocina ⭐🍽️

**Recetas de alta cocina — desde Escoffier hasta la gastronomía molecular.**

Una PWA para iPhone con 52 recetas de alta gastronomía, desde las salsas madre hasta las técnicas más avanzadas de la cocina modernista y molecular.

Cada receta incluye:
- 🛒 **Lista de ingredientes** con modo compra (checklist)
- 🔥 **Preparación** paso a paso con explicaciones detalladas de cada técnica
- 👨‍🍳 **El Chef**: historia del plato, el chef creador y el restaurante

### Contenidos

| Categoría | Recetas |
|---|---|
| Salsas madre | Bechamel, Holandesa, Velouté, Demi-glace, Tomate |
| Clásicos Escoffier | Tournedos Rossini, Soufflé, Pommes Anna, Crème Brûlée |
| Nouvelle Cuisine | Sopa de cebolla, Tarte Tatin, Magret de pato |
| Sous Vide | Huevo a 65°C, Salmón mi-cuit, Solomillo al vacío, Cigala |
| Molecular | Esferificación, Espumas, Aires, Maltodextrina, Gelificaciones |
| Firmas de chefs | Robuchon, Adrià, Bras, Bottura, Hermé, Berasategui |

### URL

🔗 **[tecladooscuro.github.io/cocinitas-avanzado](https://tecladooscuro.github.io/cocinitas-avanzado/)**

### Tech Stack

- React 19 + TypeScript + Vite 8
- Tailwind CSS v4 (tema champagne gold)
- Dexie.js (IndexedDB para lista de compra)
- PWA (vite-plugin-pwa, modo standalone)
- HashRouter (compatible con GitHub Pages)

### Instalación

```bash
npm install
npm run dev     # desarrollo
npm run build   # producción
```

### Uso en iPhone

Abre la URL en Safari, pulsa **Compartir → Añadir a pantalla de inicio**.
